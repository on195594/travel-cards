**实现一致性：通过，有局部缺口。** 保留纸白／森林绿、中文衬线标题、卡片与逐日时间线。没有重做品牌、添加依赖或改变产品契约。项目缺少 PRODUCT.md / DESIGN.md，本轮属于基于现有实现的局部精修；若要全面改版，建议先执行 `/impeccable init` 明确产品与设计方向。

## 发现与处理

共记录 7 项：P0 0 项、P1 1 项、P2 5 项、P3 1 项。

### P1 — 焦点及输入边界对比不足：已修复

- 位置：`src/app/globals.css` 的 `:focus-visible`、`--field-border`。
- 原焦点橙色对白色约 2.06:1，输入边界约 1.99:1；不满足此处非文本控件/状态辨识的 3:1 要求（WCAG 1.4.11）。
- 焦点改用主题绿色：浅色对白约 6.75:1，深色对 surface 约 7.89:1；字段边界分别约 3.41:1、4.36:1。
- 对应：`/impeccable harden`。

### P2 — 清空搜索后焦点消失：已修复

- 位置：`src/components/guide-search.tsx`。
- 清空按钮随 query 清除而卸载，键盘用户失去当前位置。清空后现在回到输入框；“全部路线”快捷按钮仍保留自身焦点。
- 浏览器断言验证了清空后 `document.activeElement` 为搜索框。
- 对应：`/impeccable harden`。

### P2 — 移动端输入与长内容：已修复局部问题

- 位置：共享 CSS 中搜索框、目的地 chips、卡片 meta、编辑器断点。
- 搜索字号原为 15.2px，存在 iOS 聚焦自动放大风险；改为 16px。长目的地快捷按钮限制最大宽度并允许换行；天数禁止压缩；编辑器在 1020px 以下提前变为单列。
- 首页在 320/390/768/1280px 无横向溢出，详情在 320/768/1280px 无横向溢出。未做真实 iOS 设备和编辑器运行验证。
- 对应：`/impeccable adapt`。

### P2 — 管理状态色没有深色变体：已修复样式

- 位置：共享 CSS 的 `.error`、`.success`、`.status.published`。
- 原样式无论主题都使用浅底状态色，与深色面板不协调。统一为语义 token，并提供深色值。未登录管理端触发全部状态。
- 对应：`/impeccable colorize`。

### P2 — 减少动态效果只缩短时间：已修复

- 位置：共享 CSS 的 reduced-motion 媒体查询。
- 原全局 `.01ms` 仍保留缩放/位移，容易产生突跳。改为明确关闭卡片及按钮位移、图片缩放和顺滑滚动，保留颜色/边框反馈。
- 首轮只断言了 Chromium reduced-motion 下卡片 hover 的 transform 为 none，不能证明所有按钮均已覆盖。AGY 后续审查发现清空与主题按钮的高优先级规则仍会缩放；现已补齐覆盖，并验证这两个按钮和目的地标签在按下状态的 transform 均为 none，普通动态模式仍保留原反馈。
- 对应：`/impeccable animate`。

### P2 — 悬浮主题按钮遮挡内容：保留，待调整

- 位置：共享 CSS 的 `.theme-toggle`、`src/app/layout.tsx`。
- 首页与详情截图显示固定右下角按钮会覆盖卡片或正文的一部分。建议下一轮将主题入口合入导航，统一处理首页、详情和管理页的入口位置，而不是再添加浮层补丁。
- 对应：`/impeccable layout`。

### P3 — 首页层级与无封面识别性：已精修

- 位置：共享 CSS、`src/components/guide-card.tsx`。
- 提升首页主标题层级和移动端顶部留白，放松卡片标题行距；无封面卡片用真实目的地代替统一占位文案，最多显示三行，保持卡片链接的可访问名称不变。
- 对应：`/impeccable polish`。

## AGY 独立复审与修复

- 审查器：真实本地 `agy` CLI，模型 `gemini-3.1-pro-high`，`--mode plan --sandbox`。以 HEAD 导出的独立副本叠加本轮变更，提供补丁及报告，只读审查；没有将其他助手冒充 AGY。
- AGY 原始输出：`docs/reviews/agy-ui-review.txt`（后续清理时从临时目录归档）。AGY 未运行浏览器，其发现由当前助手另行复现验证。
- **P2 采纳：reduced-motion 覆盖不足。** 修复前实测 `.search-clear-btn:active` 仍缩放至 0.9，`.theme-toggle:active` 仍缩放至 0.93。为减少动态媒体查询补齐同优先级选择器，并关闭清空按钮的 transform transition。仅改共享 CSS 两行，不扩大修改范围。
- **部分建议不采纳：关闭 chip 的全部过渡。** 实测 chip 在 reduce 下 transform 已为 none，保留的只是颜色过渡，无需移除有用的状态反馈。
- **P3 不采纳：双重卡片焦点框。** AGY 根据两个 outline 声明推断存在双框，但 Chromium 键盘焦点截图仅呈现容器外框，内部链接的外扩 outline 被 `.card { overflow: hidden }` 裁剪。未发现可复现缺陷，因此不额外禁用链接焦点样式；其他浏览器未验证。
- **报告纠正：** 首轮 reduced-motion 验证仅覆盖卡片，对按钮修复完整性的表述过宽。上述 P2 段落已明确首轮盲区及补测结果。
- 复验：项目 12 个测试文件 / 81 项测试通过，lint、假配置构建、Compose 配置检查、diff 检查通过。独立 `127.0.0.1:3218` 构建预览中，断言三个按钮在 reduce 模式下无缩放、普通模式下仍有原缩放，搜索清空焦点及卡片 reduced-motion 断言通过。
- 复审时通过临时 Playwright 自检脚本验证上述交互，未纳入 Vitest 套件。后续清理任务已移除该临时脚本、截图、副本和两个测试预览；本文保留的是当时的验证结果，不承诺本地预览或脚本仍存在。原 UI 提交为 `5823400`，没有新增依赖。
